# Steps to create rds instance postgres engine
Go to VPC → Subnets
Filter by VPC = the SAME VPC you’ll use
✅ Public subnet checklist:
Route table has:
0.0.0.0/0 → igw-xxxx

Pick 2 subnets in different AZs
Example:
subnet-111 (ap-south-1a)
subnet-222 (ap-south-1b)

RDS → Subnet groups → Create
Name fastapi-public-subnet-group
VPC✅ SAME VPC as subnets
Subnets ✅ Only PUBLIC subnets
AZs✅ At least 2

RDS → Create Database
Public access ✅ YES
Subnet group ✅ fastapi-public-subnet-group
Security group ✅ allow 5432

# using alembic for database migration
pip install alembic

# -t async : to use async template and alembic_dir: directory of migrations
alembic init -t async alembic_dir

# set the Config at alembic files to configure alembic
# then run to generate alembic config
alembic revision --autogenerate -m "Creating initial schema"
# should generate the schema and version file inside alembic dir

# NOT RUN for deleting postgres public schema and create from scratch
psql

# to apply generated alembic config and create db
alembic upgrade head

# to check where alembic head is like gitlog
alembic current

# after adding likes to post schema
alembic revision --autogenerate -m "Added likes field to post schema"
alembic upgrade head
alembic current
alembic history

# in case of any issue, can roll back to previous version
alembic downgrade -1

# then after fixing upgrade head again
